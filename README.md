仓库公开展示 AI 辅助概念项目，不代表已经获得 Canva 创作者认证。

适用于 GitHub Pages 的静态网站，无构建依赖。

## 本地预览

在当前目录运行 `python -m http.server 8765`，打开 http://localhost:8765 。

## 发布

将当前目录内容放到 GitHub 仓库根目录，在 Settings → Pages 选择 Deploy from a branch，选择对应分支的 / (root)，保存后访问 GitHub 返回的 Pages 地址。首次发布应实际验证。

## 项目状态

六个 AI 辅助概念项目，当前展示主视觉方向，不代表申请人既往个人原创案例。多尺寸适配与可画原生可编辑模板尚待完成。未提交创作者申请。

## 内容文件

index.html 为首页，六个案例各有独立 HTML。assets 保存 SVG 矢量源文件，cases.json 为内容记录。style.css 与 app.js 控制展示与筛选。
