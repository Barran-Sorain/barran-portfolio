# Barran创意设计

[浏览作品集](https://barran-sorain.github.io/barran-portfolio/)

品牌视觉、文化活动、自然教育、策略演示、生活方式与城市建筑主题的六组概念设计。每组包含纵版主视觉、横向版式与方形传播画面。

[下载完整作品集 PDF](downloads/Barran-Portfolio-2026.pdf)

## 本地预览

运行 `python -m http.server 8765`，访问 http://localhost:8765 。

## 文件

首页为 index.html，六个项目各有独立页面。assets/v2 保存展示图与 SVG 源文件，cases.json 保存项目文案。

## 发布

GitHub Pages 从 main 分支根目录自动部署。

## 项目说明

本作品集为概念项目展示，不对应真实商业委托、活动公告或官方认证。图片不作为现实建筑记录或商品实拍证明。源文件文字显示依赖设备字体，正式应用前请核实字体授权。
